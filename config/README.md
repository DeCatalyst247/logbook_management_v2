IT Logbook Management System

Overview

The IT Logbook Management System is a web-based platform designed to digitize the management of Students Industrial Work Experience Scheme (SIWES) and Industrial Training activities.

The system allows students to submit daily training logs, upload evidence of completed tasks, and track their progress. Supervisors can review submissions, approve or reject logs, and provide feedback. Institutions can monitor training activities through a centralized dashboard.

---

Features

Student Features

- User Registration and Login
- Student Profile Management
- Daily Log Submission
- Edit and Delete Logs
- Upload Evidence Files
- View Log Status
- View Supervisor Feedback
- Search Submitted Logs
- Export Logbook to PDF

Supervisor Features

- Supervisor Dashboard
- View Student Logs
- Approve Logs
- Reject Logs
- Provide Comments and Feedback
- Track Pending Reviews

System Features

- Authentication and Authorization
- Dashboard Statistics
- Responsive Bootstrap Interface
- File Upload Management
- Search Functionality
- PDF Report Generation
